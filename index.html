Set up Yarding for your yard

Yarding is a purpose-built tool for complete ship yard accounting. It works fully offline from the moment you finish this — no account, no internet connection, and nothing sent anywhere. Connect a cloud backend later, from Settings, whenever (and if) you want multi-device sync.

Already set up in the cloud? Connect this device instead

The administrator's device holds the database key. A remote employee gets a gate address and a yard pass only.
This app protects itself with authenticator codes, not a store login — so anyone with this URL and key could in principle read the raw database directly. Keep those two values private, and treat this like an internal tool, not a public-facing one.

Your database isn't set up yet. Open the SQL editor for your store (Supabase, or any Postgres behind PostgREST) → paste the script below → Run. Then come back and press Continue.

Last step. You are the administrator. There is no password to invent: you sign in with an authenticator app on your phone (any TOTP app — open-source ones like Aegis or Ente Auth work fine), with printable backup codes as a spare and, if you have one, a hardware security key. Later you add your workers from Settings — each gets their own.
